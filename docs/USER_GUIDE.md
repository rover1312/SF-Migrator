# User Guide

Follow the 10-step wizard in the UI:

1. Choose **New** or **Import** configuration.
2. Connect the **source org**.
3. Connect one or more **target orgs**.
4. Select **objects** to migrate.
5. Select **fields** (green = allowed, red = denied).
6. Add **filters** to scope records.
7. Run **extraction** (files land in `data/extracted/`).
8. Choose **targets** for loading.
9. Run **permission validation**.
10. Run **loading** and download the report.
